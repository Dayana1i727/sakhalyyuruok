# Саха Тыл — сайт для изучения якутского языка

Интерфейс + три рабочих урока + виджет со словом дня. Фронтенд без бэкенда: прогресс хранится в `localStorage` браузера.

## Что открывать

| Файл | Что это |
|---|---|
| **`index.html`** | Готовый сайт, один самодостаточный файл (~1,8 МБ): картинки и шрифт Montserrat вшиты в base64, работает офлайн. |
| **`widget.html`** | Отдельная страница-виджет (~90 КБ): одно якутское слово с переводом, минимализм, смена каждые 2 часа. Открывается с телефона и ставится «На экран Домой» как обычная веб-страница. |
| `src/template.html` | Шаблон разметки всего приложения. |
| `src/lesson.css` | Стили онбординга, плеера уроков, словаря, карточек изученных слов, виджета. |
| `src/lesson.js` | Логика уроков, адаптации по возрасту, прогресса, достижений, словаря, озвучки и виджета. |
| `src/widget.template.html` | Шаблон standalone-виджета (в него подставляются шрифт и список из 23 слов). |
| `build.py` | Сборка: `python3 build.py` → пересобирает `index.html` и `widget.html`. |
| `assets/` | Картинки (`assets/web` — сжатые версии для веба), шрифты, иллюстрации слов `w1…w8`, картинки фактов `f1…f9`. |

> Правки в `index.html` / `widget.html` затрутся при пересборке — меняйте файлы в `src/` и запускайте `python3 build.py`.

## Первый вход: вопрос о возрасте

При первом открытии появляется модальное окно «Сколько тебе лет?». Ответ определяет сложность заданий и сохраняется в браузере (меняется в Настройках → «Возрастная группа»).

| Группа | Режим | Что меняется |
|---|---|---|
| 6–9 лет | Юный исследователь | 3 задания в этапе, 3 варианта ответа, 3 пары, сборка слова из букв, подсказки |
| 10–14 лет | Школьник | 4 задания, 4 варианта, 4 пары, сборка слова из букв, подсказки |
| 15 лет и старше | Взрослый ученик | 5 заданий, 4 варианта, 5 пар, сборка **фразы из слов**, без подсказок |

## Уроки (6 открыто, остальные «скоро»)

1. **Знакомства** — Дорообо, Үтүө күн, аат, мин/эн, Үөрүстүм, Баһыыба, Көрсүһүөххэ диэри
2. **Бытовые фразы** — Үчүгэй / Куһаҕан, Көрдөһөбүн, Бырастыы гыныҥ, Хас?, Бу, Уу, Дьиэ
3. **Мини-диалоги** — Аатыҥ кимий?, Мин аатым Айсен, Хайдах олороҕут?, Үчүгэй баһыыба…
4. **Предложения** — саха тыла, үөрэтэбин, дьиэҕэ, барабын, үлэлиир, күн, биһиги, саҥарабыз + сборка фраз: «Мин саха тылын үөрэтэбин», «Бу кинигэ», «Биһиги сахалыы саҥарабыз»
5. **Заверши диалог** — сөп, кырдьык, бүгүн, сарсын, билигин, кэлин, эмиэ, аны + четыре диалога, где надо выбрать реплику по смыслу
6. **Еда и традиции** — Ас, Эт, Балык, Үүт, Чэй, Кымыс, Саламат, Ыһыах + сборка «Мин чэй иһэбин», «Бу эт», «Үүт амтаннаах» и четыре диалога за столом: «Аһааҥ, көрдөһөбүн» → «Баһыыба!», «Бу туох?» → «Бу балык», «Чэй иһиҥ» → «Баһыыба, иһэбин», «Ыһыахха кэлиэҥ дуо?» → «Кэлиэм!»

Каждый урок = 4 этапа, порядок фиксированный:

| Этап | Механика | XP |
|---|---|---|
| 1. Выбирать | слово на якутском → выбор перевода из 3–4 вариантов, проверка с показом правильного ответа и картинки | +10 |
| 2. Соотносить | две колонки, клик по слову и переводу (слова с большой буквы); верная пара блокируется, неверная трясётся | +5 за пару |
| 3. Конструировать | сборка слова из букв (дети/подростки) или фразы из слов (взрослые): плитки → слоты, клик по слоту убирает. В уроке 4 этап всегда из слов — собираются целые предложения | +15 |
| 4. Проверка себя | карточки со скрытым переводом (тап — показать) и кнопками озвучки, «Знаю» / «Повторить» | — |

В конце — экран результата: точность, +XP (включая бонус +30 за урок), «Следующий урок» / «Пройти заново». Кнопка «Назад» возвращает на предыдущий шаг.

**Урок 5 «Заверши диалог»** устроен как чат: Кыыс Куо говорит реплику («Аатыҥ кимий?» — «Как тебя зовут?»), под ней три варианта ответа, выбрать нужно по смыслу. Верный — зелёный, неверный красный, в подсказке показан логичный ответ и его перевод. Этап идёт вместо «Конструировать» и тоже даёт +10 XP.

Все слова, переводы и варианты ответов в уроках показываются с заглавной буквы — и якутские, и русские (в словаре тоже). Плитки внутри сборки фразы остаются строчными, как в настоящем предложении: «Мин саха тылын үөрэтэбин».

## Исправления грамматики (итерация 12)

Сверено по якутско-русскому словарю (sakhatyla.ru / Большой толковый словарь якутского языка):

| Было | Стало | Почему |
|---|---|---|
| Аатыҥ хайдаҕый? | **Аатыҥ кимий?** | об имени спрашивают через «кимий» («кто»), «хайдаҕый» — «какой по качеству» (хайдаҕый — про дом, погоду) |
| Хайдах олоҕоҕут? (урок 5) | **Хайдах олороҕут?** | форма от «олор» (жить) — 2-е лицо мн. ч.: олороҕут; словарь даёт именно «хайдах олороҕут?» |
| дьиэҕэ — «домой» | дьиэҕэ — **«к дому, в дом»** | дьиэҕэ — дательный падеж «к дому»; «домой» = дьиэбэр (к себе домой) |

Заодно: счётчики курса больше не зашиты на трёх уроках (`/3`, «Пройди все уроки», «первый нерешённый урок», «следующий урок») — теперь они считаются по числу уроков в контенте.

Полоса этапов («Выбирать · Соотносить · Конструировать · Проверка себя») скрыта — остались только тонкая полоса прогресса и подпись «Шаг 4 из 7 · Соотносить».

## Постоянный символ над уроками

- На странице «Уроки» сверху закреплена полоса с символом приложения — Кыыс Куо в рамке-иконке — и приветствием. Она `position: sticky`, поэтому остаётся на экране при прокрутке списка уроков и не исчезает; иконка мягко покачивается (при `prefers-reduced-motion` анимация отключается). В тёмной теме полоса перекрашивается.

## Алфавит

- Отдельный раздел **«Алфавит»**: 40 букв, разложенных на группы — **Гласные · 8**, **Долгие гласные · 8**, **Дифтонги · 4** (ыа, иэ, уо, үө), **Согласные · 26**, **Знаки · 2** (ъ, ь).
- Фильтры сверху: Все / Гласные / Долгие / Дифтонги / Согласные.
- Каждая плитка нажимается: звучит буква, рядом появляется Кыыс Куо с подсказкой («ө — «о» с губами как при «у», нем. ö»). Буквы, которые встречаются только в заимствованиях (в, ж, з, ф, ц, ш, щ), помечены точкой.
- Каждая плитка озвучивается так же, как слова в словаре: на ней есть маленький значок динамика, а звук — запись того же диктора (не системный синтезатор). Записаны все гласные, долгие гласные, дифтонги и основные согласные; ө/ү звучат по-настоящему, как турецкие ö/ü. Оставшиеся буквы (а, э, и, о, у, ы, ж, з, й, п, р, с, һ, т, ф, х, ц, ч, ш, щ) пока читает системный голос с тюркской подстановкой — их перезапись в работе, лимит озвучки 10 клипов за ход.

## Словарь русский → якутский

Пункт **«Словарь»** в меню — 155 слов в 12 темах: приветствия, люди и семья, местоимения и вопросы, числа, цвета, природа, животные, еда, дом и город, действия, признаки, время.

- Слева русское слово, справа — якутский перевод синим, у каждого слова кнопка со звуком. Нажатие на само слово или на перевод тоже озвучивает якутский вариант (как в Duolingo).
- Строка поиска ищет сразу по обеим сторонам: «вода» и «уу» находят одно и то же. Фильтры-темы сверху отсекают лишнее, счётчик показывает, сколько слов найдено, кнопка «Сбросить» возвращает полный список.
- Слова лежат в `build.py` в списке `DICT` (пары «русское — якутское»), разметку собирает `dict_group()`, поиск и фильтры — в `src/lesson.js`. Новое слово = одна пара в `DICT`.

**Известные люди Якутии** — отдельный блок на той же вкладке, 6 карточек: Суорун Омоллоон (Дмитрий Сивцев), Платон Ойунский, Алексей Кулаковский, Семён Данилов, борец Роман Дмитриев (первое олимпийское золото Якутии, Мюнхен-1972) и кинорежиссёр Дмитрий Давыдов («Пугало», Гран-при «Кинотавра»-2020). У каждого — имя, годы, роль и пара фактов. Список людей и тексты — `PEOPLE` в `build.py`, картинки — словарь `PERSON_IMG`.

## Нажми на слово — услышишь его

- Любое якутское слово в приложении кликабельно: слово в задании, плитка в сборке, слово в «Соотносить» (заодно озвучивается при верной паре), слово в самопроверке и в словаре.
- Рядом появляется **Кыыс Куо** с облачком: слово, перевод и подсказка «Слушай и повторяй». Во время звука у неё **открывается рот** — два кадра (закрытый/открытый), переключаются в такт воспроизведению, поэтому похоже на настоящую артикуляцию.
- Перевод в облачке показывается, когда он уже не подсказка: после проверки ответа, после собранной пары, в самопроверке и в словаре. До проверки видно только слово — иначе упражнение теряет смысл.
- В облачке перевод стоит **рядом с якутским словом** в одну строку: «Дорообо — Привет» (прочерк рисуется стилями, отдельной строки больше нет).
- Символ появляется **и от нажатия на кнопку-динамик** (в задании, в самопроверке, в словаре — там сразу с переводом), и от нажатия на само слово.
- Подсказка выходит **по центру экрана вверху** (по горизонтали ровно по середине окна, на 15 % высоты от верха), а не в углу. На телефоне это цельная карточка с иконкой и текстом — под ней ничего не просвечивает. Через 5 секунд подсказка плавно уходит.

## Звук и маскот

- Звуковые отклики собраны на WebAudio, без файлов: лёгкая «капля» при выборе, восходящая терция-колокольчик при верном ответе (и в паре, и в сборке), мягкий низкий тон при ошибке, мажорное арпеджио на финише урока, «искорки» при новом достижении. - Выключается в Настройках → «Звуки и озвучка» (состояние сохраняется).
- **Кыыс Куо** — маскот приложения, девочка из олонхо в якутской зимней одежде с орнаментом (файлы `assets/mascot.png`, `assets/web/mascot.jpg`, лицо для аватара `assets/web/mascot-face.jpg`). Встречает в окне выбора возраста и появляется на экране результата урока.

## Виджет на телефон (новое)

- Раздел **«Виджет»** в меню: превью на телефоне (крупный, средний и малый размеры), панель «Слово сейчас» с озвучкой и кнопкой «другое», инструкция по установке и скачивание PNG 1080×1080.
- Слово берётся детерминированно: `WW[Math.floor(Date.now() / 7200000) % 23]` — одно и то же слово у всех в течение 2 часов, смена на границе двухчасового слота. Внизу таймер «до смены h:mm:ss».
- **`widget.html`** — та же логика отдельной страницей в стиле минимализма: белая карточка, только «САХА ТЫЛ», слово, перевод, две кнопки озвучки и «смена через …». Авто-тема под системную (`prefers-color-scheme`). Ставится на домашний экран телефона как веб-страница и работает без интернета.
- Системный виджет iOS/Android (WidgetKit / App Widget) требует нативного приложения — это следующий шаг, страница и PNG дают эквивалент без установки из App Store.

## Звуки якутского: чей голос ближе

В якутском есть звуки, которых в русском нет вообще, поэтому «ө» и «ү» никакой русский голос правильно не скажет. Зато они есть в тюркских языках, и там буквы читаются почти один в один с якутскими:

| Якутский | Звук | Русский голос | Турецкий | Азербайджанский | Казахский |
|---|---|---|---|---|---|
| ө | [ø] | ё / о | **ö** | **ö** | **ө** |
| ү | [y] | ю / у | **ü** | **ü** | **ү** |
| ы | [ɯ] | ы | **ı** | **ı** | **ы** |
| ҕ | [ɣ] | г | **ğ** | **ğ** | **ғ** |
| һ | [h] | х | **h** | **h** | **һ** |
| ҥ | [ŋ] | нг | **ng** | **ng** | **ң** |
| х | [x] | **х** | h | **x** | **х** |
| дь / нь | [ɟ] / [ɲ] | дь / нь | c / ny | c / ny | дь / нь |

Поэтому синтезатору теперь можно подсунуть не русскую, а тюркскую запись: текст переписывается латиницей (`Ütüö kün`, `Kuhağan`, `Bırastıı gınıng`), а голос берётся турецкий или азербайджанский. Азербайджанский ближе всех: в нём есть и **ğ** [ɣ], и **x** [x].

- Настройки → **«Звуки якутского»**: `авто` / `русский` / `турецкий` / `азербайджанский` / `казахский`.
- `авто` — самый аккуратный режим: для слов с ө/ү/ҕ/һ/ҥ берётся тюркский голос (если он есть в системе), остальные слова читает привычный русский; конкретный голос выбирается в строке «Голос» — если выбрать голос вручную, фонетика подстроится под его язык.
- Для русского голоса подстановка тоже стала точнее: ө/ү после согласной дают «ё/ю» (мягкость), а в начале слова и после гласной — «о/у», без лишнего «й»: `Үтүө күн` → «Утюо кюн» вместо «Ютюё кюн».
- То же самое умеет `tools/phon.py`: `respell_for(text, 'ru' | 'tr' | 'az' | 'kk')` — пригодится, если перезаписывать слова тюркским голосом.
- Записи из `assets/audio` по-прежнему в приоритете: если для слова есть mp3, играет он, а синтезатор с фонетикой включается только для слов без записи.

## Озвучка

- Обе стороны озвучиваются: кнопки **«саха»** и **«RU»** в словаре, в самопроверке и в виджете.
- **Один голос на всё приложение.** Записи озвучки сделаны одним диктором (тюркский женский голос: он правильно читает ө/ү/ҕ/һ/ҥ), а системный синтезатор в режиме «один голос» тоже берёт один и тот же голос для всех якутских слов — приложение не перескакивает между русским и тюркским голосом. Смена голоса — только вручную в Настройках.
- **Якутские слова записаны заранее** женским голосом и вшиты в файлы (`assets/audio/*.mp3` → base64 в `index.html` и `widget.html`): мягкая, плавная подача, средний темп, одинаково на любом устройстве. Скорость из Настроек влияет и на записи (`playbackRate`). Записи прежние, дикторские — они возвращены как были (итерация 11: правка звучания откатили по просьбе).
- Записаны **28 фраз**: все слова урока 1, слова уроков 2–4, две фразы урока 1 и девять гласных алфавита; остальное читает системный голос. Реестр записей — `assets/audio/manifest.json` (ключ = якутское написание, совпадение не зависит от регистра и точки в конце), добавить новое слово = положить mp3 и дописать строку.
- Русская сторона читается системным голосом: из голосов браузера выбирается женский русскоязычный (эвристики по названиям + фильтр по языку), `rate 0.9`, `pitch 1.04`. В Настройках можно вручную выбрать голос и скорость (0.75 / 0.9 / 1.05).
- Резервный системный голос получает **заранее переписанный по-русски текст** (`tools/phon.py` → `sahPhon()` в `src/lesson.js`): ө→ё, ү→ю, ҕ→г, ҥ→нг, һ→х, поэтому без записи слово всё равно звучит ближе к якутскому («кюн», «бахыыба», «сангарабыз»). Названия букв алфавита тоже подставляются по-русски: «бэ», «га», «нга», «ха» (таблица `LETTER_SAY`), а ь/ъ не озвучиваются вовсе.
- Ограничение: и запись, и TTS читают якутский с русской фонетикой (ҕ, ҥ, ө, ү звучат приблизительно). Точное произношение даст только диктор-носитель.

## Прогресс и достижения (всё считается на реальных данных)
